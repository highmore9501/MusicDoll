# fix-subtitle 技能说明

## 核心工作流程（人工驱动，不可用脚本批量处理）

```
步骤1: 通读全文 → 步骤2: 整体修复 → 步骤3: 按自然断句分配回时间轴
```

### 步骤 1：提取全部文字和时间轴

读取整个 `.srt` 文件，分别提取：

- **时间轴列表**：有序保留每个字幕块的序号和时间戳（`00:00:40,500 --> 00:00:41,200`），**绝不修改**
- **纯文本内容**：按顺序提取每个字幕块的文字内容，形成字符串数组 `texts[]`

### 步骤 2：合并为连续文本并通读理解

将所有文字内容拼接成一个连续的段落，**通读一遍理解语义**。例如：

```
"好的各位观众老爷你们好 那么这集视频的话呢 是一个视频资料推荐 ..."
```

**关键**：修复前必须理解这段话在讲什么，否则无法正确判断哪些是口癖、哪些是识别错误。

### 步骤 3：整体修复（人工，不可用脚本/正则批量替换）

以**整段文字**为单元进行手动修复。逐句阅读，凭语感判断修复内容。修复内容包括：

#### 3a. 删除口癖/填充词

- `呃`、`啊`、`哦`、`哈`、`呀` 等语气词 → 删除
- `的话呢` → 删除，或简化为 `的`
- `那么`（句首无实际意义时）→ 删除
- `这个`（用作口头禅/垫话时）→ 删除
- `然后的话呢` → `然后`
- `最终的话呢` → `最终`
- `所以的话` → `所以`
- `再一个的话呢` → `再一个`
- `我有一个...我有个...` → 保留有意义的，删除重复垫话
- `好的`（独立成句时）→ 删除
- `就是说` / `就说` / `就是`（垫话）→ 视上下文删除

#### 3b. 修复语音识别错误

- 发音相似的错误：`钢钢琴` → `钢琴`、`我擅擅长` → `我擅长`
- 代词错误：`他`（指代事物时）→ `它`、`他们`（指代事物时）→ `它们`
- 专有名词：`Arry/arrear/arirae` → `Unreal`、`Kriver` → `KeyRipple`、`musicodol` → `MusicDoll`
- 中英混杂：`lip SYNC` → `Lip Sync`、`sequence` → `Sequence`
- 上下文推断：`我留言` → 根据视频内容判断是否为`浏览`或其他

#### 3c. 精简冗余表达

- `去进行驱动` → `去驱动`
- `重新再分轨` → `重新分轨`
- `有出了很多的一些之前出的视频` → `出了很多之前的视频`
- `你可以来...你可以去...` → 合并

### 步骤 4：分配回时间轴（人工，不可用脚本批量处理）

修复完成后，**逐条手动**将修复后的文本分配到原有的时间轴中。

分配规则：

1. **保持原有时间轴数量和顺序不变**
2. 按自然语意断句分配到对应时间段（句号处可切，逗号处酌情）
3. **某些时间轴可以留空**——比如原字幕中纯口癖的时间段（"呃"、"这个"、"好的"等）直接清空
4. 一条时间轴的文字如果放不下一个完整句子，可以延续到下一条
5. 如果修复后文字量显著减少，后半部分时间轴自然留空

### 分配示例

**修复前**：

```
17    00:00:40,500 --> 00:00:41,200    这个
18    00:00:41,200 --> 00:00:44,700    它用到了很多的开源库
19    00:00:44,800 --> 00:00:48,533    呃他是可以去将一个歌曲
```

**修复后**（17 被清空，文字分配到后续时间轴）：

```
17    00:00:40,500 --> 00:00:41,200
18    00:00:41,200 --> 00:00:44,700    它用到了很多的开源库
19    00:00:44,800 --> 00:00:48,533    它可以将一个歌曲
```

```

## 注意事项

- **绝不修改时间轴**（序号和时间戳完全不动）
- 修复后文字为空的时间轴，保留序号和时间戳，文字行留空即可
- 专有名词拿不准的，先搜索项目文件确认
- 修复完毕后检查一遍整体通顺度
- 如果要处理的文字量大，整个工作流程可以分两次对话完成，不必拘泥于一次性完成。
```
