# 字幕翻译技能 (translate-subtitle)

## 目标

将中文字幕文件（.srt 格式）翻译为英文，保持原时间轴不变，生成一个独立的新文件。

## 核心原则

### 1. 不修改时间轴

- 原字幕中的序号、时间轴（`00:00:02,533 --> 00:00:05,433`）**绝对不允许修改**
- 每条字幕的序号必须与原文保持一致
- 时间轴格式必须保持 SRT 标准格式：`hh:mm:ss,mmm --> hh:mm:ss,mmm`

### 2. 英语母语者表达习惯

- 不搞逐字直译，要用自然、地道的英语表达
- 适当合并或拆分语句，使英语读起来通顺
- 对于中文中常见的口语填充词（如"那么"、"然后"、"所以"等），根据上下文决定是否翻译或省略
- 对于中文特有的语气词（如"呢"、"吧"、"嘛"），转化为英语对应的表达方式
- 专有名词保持原文（如 Blender、Unreal、Bilibili、YouTube、MIDI 等插件/工具名）
- 对于中文中"观众老爷"、"各位"等称呼语，译为自然英语表达如 "Hello everyone", "welcome to my channel" 等

### 3. 空字幕条目的处理

- 原文中时间轴下方没有文字（空行）的条目，在翻译文件中保持空行不变
- 不要试图为空白字幕填充内容

### 4. 文件命名

- 翻译后的新文件放在原文件同目录下
- 命名规则：在原文件名基础上加 `_en` 后缀，例如：
  - `视频推荐油管版_修复版.srt` → `视频推荐油管版_修复版_en.srt`
  - `intro.srt` → `intro_en.srt`
- 如果 `_en` 文件已存在，则覆盖更新

### 5. 格式检查

- SRT 格式要求：序号行 → 时间轴行 → 字幕文本行 → 空行（作为分隔）
- 翻译完毕后检查文件格式是否正确、完整
- 确保没有遗漏条目

## 常见翻译处理示例

| 中文原文                   | 英语翻译                                       | 说明                   |
| -------------------------- | ---------------------------------------------- | ---------------------- |
| 各位观众老爷你们好         | Hello everyone, welcome to my channel.         | 意译，符合英语开场习惯 |
| 这也没办法                 | It can't be helped.                            | 自然英语表达           |
| 再接下来就是               | Next up is                                     | 简洁自然               |
| 因为油管的流量太少了       | The traffic on YouTube is just too low.        | 保留 YouTube 原名      |
| 3d WorkFlow Animation      | "3D WorkFlow Animation"                        | 专有名词不翻译         |
| 卡哇伊插件                 | the Kawaii plugin                              | 专有名词首字母大写     |
| 你实际上都需要看这一个视频 | you really need to watch this particular video | 语气准确传达           |
| 所以还是那句话             | So, as I said,                                 | 口语化的自然衔接       |

## 执行流程

1. 通读原字幕全文，理解视频的整体内容与语境
2. 逐条对照翻译，保持序号和时间轴不变
3. 创建新文件，写入翻译结果
4. 最终校验：确保条目数一致、时间轴无改动、格式正确
5. 如果处理的文字内容比较多，不要拘泥于一次对话完成全部任务，可以尝试多次对话来完成。
